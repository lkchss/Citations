# Economics subject time series

All pre means use event years −5:−1. All post means use event years 0:+4.

## Original pattern

![Original economics time series](../8.7.26/economics_subject_level/economics_big_hit_event_time.svg)

**Pre group:** 75,882 author–focal-paper–hit units in each event year −5:−1.
Rows before the focal paper was published are included as zero citations.

|---:|---:|---:|---:|---:|---:|---:|---:|

## Paper-age controls

| Changing paper set | Same paper set |
|---|---|
| ![Changing-sample age comparison](../8.7.26/economics_paper_level_normalized/original_pattern_with_age_control.svg) | ![Fixed-sample age comparison](../8.7.26/economics_paper_level_normalized/same_papers_vs_typical.svg) |
| **Pre group:** papers already published in each year −5:−1. The sample increases from 42,447 units at −5 to 75,882 at −1. | **Pre group:** the same 14,076 units in every year −10:+10; pre mean uses years −5:−1. |

For each author paper-year, the comparison papers have the exact same paper
age, calendar year, and document type.

| Sample | Authors' pre | Authors' post | Same-age pre | Same-age post | Relative change |
|---|---:|---:|---:|---:|---:|
| Changing paper set | 0.660 | 0.870 | 0.522 | 0.618 | +0.114 |
| Same paper set | 0.519 | 0.461 | 0.525 | 0.529 | −0.063 |

| Changing-set decline | Year 0 | Year +10 | Decline |
|---|---:|---:|---:|
| Authors' older papers | 0.912 | 0.535 | −0.377 |
| Same-age papers | 0.616 | 0.488 | −0.128 |

Normal paper aging accounts for 34.0% of the changing-set decline from year 0
to +10.

## Big picture

- Original: citations rise before year 0, peak near years 0:+1, then decline.
- Changing set with paper-age control: +0.114 relative pre/post change.
- Same set with paper-age control: −0.063 relative pre/post change.
- Positive trend appears only when the set of papers changes over time.
